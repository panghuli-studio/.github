# Panghuli Studio

An independent software studio by [phenix3443](https://github.com/phenix3443), building developer tools and self-hosted software.

## Explore

| Project | What it does |
| --- | --- |
| [Agent Store](https://github.com/panghuli-studio/agent-store) | A web store and desktop client for skills, MCP servers, and model providers. |
| [PPanel server](https://github.com/panghuli-studio/ppanel-server) | Backend services for the PPanel ecosystem. |
| [PPanel frontend](https://github.com/panghuli-studio/ppanel-frontend) | Web interfaces for PPanel. |
| [PPanel node](https://github.com/panghuli-studio/ppanel-node) | A PPanel node service based on Xray. |

Each repository documents its own setup, license, and release status. Archived repositories remain available for reference.

## Get involved

Start with the project's README. Use its Issues for reproducible bugs and feature proposals, and keep pull requests focused on one change. Shared guidance is in [CONTRIBUTING.md](https://github.com/panghuli-studio/.github/blob/main/CONTRIBUTING.md).

For vulnerabilities, use the affected repository's private security reporting channel. See our [security policy](https://github.com/panghuli-studio/.github/blob/main/SECURITY.md).
